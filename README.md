
# Computadora de Vuelo y Sistema de Telemetría para Cohete Experimental
## Descripción del Proyecto
Este repositorio contiene el código fuente y la arquitectura de software desarrollada para la computadora de vuelo de un cohete experimental de ámbito académico. El sistema está diseñado en torno a microcontroladores ESP32 y utiliza arquitecturas de tiempo real compatibles con FreeRTOS para la gestión de adquisición de datos y control de actuadores.

# Descargo de Responsabilidad (Aviso de Uso Crítico)
ADVERTENCIA: Uso estrictamente académico y experimental.
Este software y arquitectura fueron diseñados con fines puramente educativos. Este proyecto integra componentes comerciales como los sensores Bosch (BMP280), InvenSense (MPU6050) y receptores u-blox. Las hojas de datos y directrices legales de estos fabricantes prohíben explícitamente el uso de sus componentes en sistemas críticos para la vida, aplicaciones aeroespaciales, tecnología de misiles, o cualquier sistema donde un fallo pueda resultar en daños a la propiedad o riesgo para la seguridad humana.
El código se proporciona sin garantías de tolerancia a fallos. La reutilización de esta lógica para el control de cohetes físicos u objetos voladores es bajo el propio riesgo y responsabilidad del usuario.
